## What I'm Building

### ApplyAide
**Job Application Assistant · Personal Project**

A browser extension and companion web app I built after getting tired of repeatedly checking sponsorship language, entering the same application information, and manually tracking jobs.

- Scans job postings for sponsorship and work-authorization language with explainable evidence
- Autofills application fields with safeguards for sensitive questions
- Tracks saved and applied jobs
- Syncs application data with Google Sheets
- Uses Google OAuth and server-side session management
- Runs on a serverless AWS backend

**Tech:** TypeScript, React, Chrome Manifest V3, AWS Lambda, API Gateway, DynamoDB, S3, CloudFront, Google OAuth, Google Sheets API, GitHub Actions

🔗 [applyaide.manushri.dev](https://applyaide.manushri.dev)

### PawPal AI
**RAG-Based Pet Health Record Assistant · CodePath AI110**

Started as a pet-care scheduling application and evolved into an applied AI system for organizing information from pet health records.

- Built a document-processing and retrieval pipeline for vaccine, medication, appointment, and due-date information
- Added evidence grounding, field-level citations, contradiction detection, and human approval
- Used deterministic Python logic for reminders and validation instead of trusting model output blindly
- Built a reliability evaluation suite alongside automated testing

**Tech:** Python, Streamlit, pytest, SQLite, RAG, embeddings, vector search, Anthropic API

🔗 [GitHub Repository](https://github.com/manushri1415/PawPal-Pet-Care)
